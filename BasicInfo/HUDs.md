# 🧰 Script Toolbar

This section explains each tool available in the Script editor toolbar in detail.

---

## ⬅️ Back
A navigation tool that lets you return to the **previous position in your script history**.

It is useful when:
- 🔙 You jump between different parts of your code
- 🧭 You want to quickly return to where you were editing before


## ➡️ Forward (Fwd)
Moves you forward in your **script navigation history** after using the Back button.

It is useful when:
- 🔄 You went back too far and want to return to a later position
- 🧭 You are navigating between multiple code locations

---

## 📜 Script
Opens or focuses the **currently active script** you are working on.

It helps you:
- 🧩 Quickly return to the script you were editing
- 📂 Stay organized when multiple scripts are open

---

## 🎨 Format
Automatically formats your code to improve **readability and structure**.

It is useful for:
- 🧼 Cleaning messy or unorganized code
- 📏 Aligning indentation properly
- 📖 Making scripts easier to read

---

## 🔍 Find
A search tool that lets you look for **specific words or code** inside your script.

It is useful for:
- 🔎 Finding variables, functions, or events quickly
- 🧭 Navigating large scripts without scrolling manually
- ⚡ Saving time when editing complex systems

---

## 📍 Go to Line
Allows you to jump directly to a **specific line number** in your script.

It is useful for:
- 🎯 Debugging errors from the Output window (which often show line numbers)
- 🧭 Navigating large scripts instantly

---

## 💻 Command
Opens the **Command Bar**, where you can type and execute manual commands to test your scripts.

It is useful for:
- 🧪 Testing functions quickly
- 🔧 Debugging game behavior in real time
- ⚙️ Running actions without modifying the script directly

---

## 📤 Output
Displays **logs, warnings, errors, and debug information** from the game.

It is useful for:
- 🐞 Detecting script errors
- 📊 Monitoring system messages
- 🧾 Seeing print/warn outputs from scripts

---

## 🔴 Breakpoints
Allows you to set **breakpoints** that pause script execution at specific lines.

It is useful for:
- 🐞 Debugging step by step
- ⏸️ Freezing the game at a specific point in code
- 🔍 Inspecting variables at runtime

---

## 🧵 Call Stack
Shows the **sequence of function calls** that led to the current point in execution.

It is useful for:
- 🧠 Understanding how code reached a specific state
- 🐞 Debugging complex function chains
- 🔗 Tracking nested function calls

---

## 👁️ Watch
Lets you monitor **variables in real time** while the game is running.

It is useful for:
- 📊 Tracking variable changes
- 🧪 Debugging logic issues
- 👀 Observing values without printing them manually

---

## 📊 Analysis
Provides **code analysis and insights** about your scripts.

It is useful for:
- ⚠️ Detecting potential issues
- 🧠 Understanding script behavior
- 📈 Reviewing code structure

---

## ⚡ Performance
Shows **performance metrics** of your game and scripts.

It is useful for:
- 🚀 Identifying lag sources
- 📉 Monitoring script efficiency
- 🧩 Optimizing game performance
